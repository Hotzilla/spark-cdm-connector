# Releasing the Spark 3.5 connector

This repository includes a GitHub Actions workflow that builds the Spark 3.5 assembly jar and uploads it to a GitHub Release. The jar is not committed to the repository; it is generated by the workflow and attached to the release.

## Workflow

Workflow file: `.github/workflows/release-spark35.yml`

The workflow runs in two ways:

1. **Manual dispatch** from the GitHub Actions UI.
2. **Tag push** for tags that match `spark3.5-*`.

The workflow builds with Java 17 and runs:

```bash
sbt clean assembly
```

It uploads two release assets:

- `spark-cdm-connector-assembly-synapse-spark3.5-<version>.jar`
- `spark-cdm-connector-assembly-synapse-spark3.5-<version>.jar.sha256`

## Before running the workflow

You need:

1. The Spark 3.5 code pushed to the `spark3.5` branch on GitHub.
2. Repository Actions enabled.
3. Workflow permissions that allow GitHub Actions to create releases:
   - Repository **Settings** > **Actions** > **General** > **Workflow permissions**
   - Select **Read and write permissions**.

No long-lived personal access token is required for this workflow because it uses GitHub's built-in `GITHUB_TOKEN` with `contents: write` permission.

## Option A: Trigger manually from GitHub

1. Open the repository on GitHub.
2. Go to **Actions**.
3. Select **Release Spark 3.5 Connector**.
4. Click **Run workflow**.
5. Choose the `spark3.5` branch.
6. Enter:
   - `tag_name`: for example `spark3.5-1.19.7`
   - `release_name`: for example `Spark CDM Connector spark3.5-1.19.7`
   - `prerelease`: usually `false`
7. Click **Run workflow**.

The workflow creates or updates the GitHub Release for the tag and uploads the generated jar plus checksum.

## Option B: Trigger by pushing a tag

From a local clone on the Spark 3.5 branch:

```bash
git fetch origin --prune
git checkout spark3.5
git pull --ff-only origin spark3.5
git tag spark3.5-1.19.7
git push origin spark3.5-1.19.7
```

Pushing a tag matching `spark3.5-*` triggers the release workflow automatically.

## If the `spark3.5` branch is missing locally

Fetch it from GitHub:

```bash
git fetch origin --prune
git checkout -b spark3.5 origin/spark3.5
```

If that command fails with `origin/spark3.5` not found, the branch has not been pushed to the remote that your local `origin` points to. Push the branch first, or update `origin` to the GitHub repository/fork that contains it.
